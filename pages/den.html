A real code editor, made for learning.

Type den in a folder and it opens in your browser: files, search, git, terminals, two files side by side and live previews, plus Ember the fox, who explains words and errors in plain English and can change your code with you, showing exactly what changes first.

Everything the pros use, nothing in the way

    
den does what big editors do, with the confusing parts taken out and a friend added in.

    

      
Run, and fix it
One button runs your code: Python, JavaScript and about a dozen more, and input() questions are answered right in the console. When something breaks, Ember says what it means, points at the line, and can fix it with you: she shows the exact change, green for added and red for removed, before anything happens.

      
Mistakes, as you type
A squiggle under the problem and the reason when you point at it, before you even press Run (Python, JavaScript, JSON, CSS).

      
Terminals
Real ones, built in: colours, arrow keys, python3 on its own, pip install, git, anything.

      
Changes
git, made friendly: coloured bars beside changed lines, commit with one button (Ember can write the message), and put your project on GitHub.

      
Search everything
Find and replace across every file, with whole-word and pattern options and a preview of each change.

      
Two files, side by side
Your code on the left and your web page or game running on the right, updating as you type. A map of the whole file, indent lines, matching brackets, and a path bar that shows which function you're in.

      
What's this?
Put your cursor on a word like for, def or padding, and Ember explains it with a tiny example.

      
Start from an example
A web page, a Python program, a quiz, notes, or an arcade game you can play the moment it opens.

      
Nothing gets lost
den saves as you type, keeps earlier versions of every file, and deleting only moves things to den's bin.

Ember's AI is free

      
The word explanations and error help work with no AI at all. To also ask Ember questions, set up free AI once in Tree of Thought: install it from pca, type tot free and follow the steps. It runs in the cloud, so nothing heavy runs on your computer.

      
Ember only suggests. When she writes code, Apply shows you exactly what would change before anything does, and ⌘Z undoes it.

      
Safe by design

      
den only listens on your own computer, behind an address with a long secret in it, so websites you visit can't reach it. It only touches the folder you opened, previews your pages from a separate address, and never runs anything unless you press Run, type a command or use a terminal.

    

    

      
Keys worth knowing

      
On Windows, use Ctrl where this says ⌘.

      

        
⌘ Enterrun the file you're on

        
⌘ Pfind a file (then > for commands, @ for functions, : for a line)

        
⌘ Eask Ember to change your code (you see the change first)

        
⌘ ⇧ Fsearch and replace in every file

        
⌘ \two files side by side

        
Ctrl `a terminal

        
⌘ /turn lines into comments, and back

        
F8jump to the next mistake
