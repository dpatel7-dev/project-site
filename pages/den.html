Everything a beginner needs, nothing in the way

    
den looks like the editors the pros use, with the confusing parts taken out and a friend added in.

    

      
▶ Run
One button runs your code: Python, JavaScript and about a dozen more. If your program asks a question with input(), you answer it right in the console. When something breaks, Ember says what it means, points at the line, and can install a missing module for you.

      
What's this?
Put your cursor on a word like for, def or padding, and Ember explains it with a tiny example.

      
Preview
See your web page next to its code as you type. Its console.log and errors show up in den too. Markdown notes, pictures and tables preview as well.

      
Ask Ember
Ask anything about your code. Ember sees the file you have open and suggests changes you can put in with one click (and undo). She uses Tree of Thought's free AI.

      
Nothing gets lost
den saves as you type and keeps earlier versions of every file. Deleting only moves things to den's bin, so you can always put them back.

    

  


  

    
Your first program, start to finish

    
No setup screens. If you can type in a terminal, you can do this.

    
    
      
  1. Install den with the command at the top (or pca).
    2. 
      
  2. Make a folder for your project: type den my-game. den offers to make it.
    3. 
      
  3. Press + file and name it game.py (or index.html for a web page). An empty file? Ember offers a starting point.
    4. 
      
  4. Press ▶ Run. Change something, run it again. That's coding.

Ember's AI is free

      
The word explanations and error help work with no AI at all. To also ask Ember questions, set up free AI once in Tree of Thought: install it from pca, type tot free and follow the steps. It runs in the cloud, so nothing heavy runs on your computer.

      
Ember only suggests. Your files change only when you press Put in file, and ⌘Z undoes it.

      
Safe by design

      
den only listens on your own computer, behind an address with a long secret in it, so websites you visit can't reach it. It only touches the folder you opened, previews your pages from a separate address, and never runs anything unless you press Run.

    

    

      
Keys worth knowing

      
On Windows, use Ctrl where this says ⌘.

      

        
⌘ Enterrun the file you're on

        
⌘ Pfind a file by typing part of its name

        
⌘ ⇧ Fsearch every file

        
⌘ Ffind and replace in this file

        
⌘ /turn lines into comments, and back

        
⌘ Keverything den can do: just type what you want

        
Tabpush lines in (Shift+Tab pulls them out)

        
?every key
