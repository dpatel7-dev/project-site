Your first time in Terminal

Terminal is an app where you type short commands instead of clicking. It looks scary but it's just typing. Follow these steps; each one shows exactly what you'll see.

  1. Open Terminal

    Open PowerShell

    Hold the command key and press space. A search box pops up. Type Terminal and press return.

    Press the Windows key. Type PowerShell and press Enter.

    ⌘ command + space
    ⊞ Windows
    TerminalSpotlight
    >_Terminal

  2. A window like this opens

    The last line ends with %> and a blinking block. That means it's waiting for you to type.

    TerminalWindows PowerShell
    Last login: Tue on ttys000
you@Mac ~ %  
    Windows PowerShell
PS C:\Users\you>

  3. Copy this line

    Click Copy. You don't need to understand it: it downloads pca, a menu that installs all the apps for you.

    curl -fsSL {{origin}}/pca/install.sh | sh

  4. Paste it into the window, then press Enter

    Click on the Terminal window. Hold command and press V to paste. Then press return.

    Click on the PowerShell window. Right-click once to paste. Then press Enter.

    ⌘ command + V then return
    right-click then Enter

    Words scroll by for a minute while it installs. That's normal. Wait until you see this:

    installing
      Downloading pca…
  Setting up…
  ✓ Done! Pick a project:  pca

  5. Type pca and press Enter

    If it says command not found, close the window, open a new one (step 1), and try again.

    pca
    you@Mac ~ % pca

  project cli access  ·  one command, every project
  gossiptree of thoughtpigeontidyscoutroomydenheymorphshoo
  ← → choose · enter installs and opens scout

  6. Pick an app with the arrow keys, then press Enter

    The first time, it installs itself (about a minute), then it opens. Next time, just type its name: scout, roomy, hey…

    ←→ to choose, return to open, q to quit
That's it. You never have to do this again: pca keeps every app up to date by itself.

Words you'll see

Terminal
The app where you type commands. On Windows it's called PowerShell.
Command
A short line you type, like scout or roomy, then press Enter.
Enter / return
The big key on the right of the letters. It means "go".
Paste
Putting in what you copied: ⌘ command + V on a Mac.
Esc
The key in the top-left corner. It means "go back" in these apps.
Ctrl + C
Stops whatever is running in Terminal, if you're ever stuck.

If something goes wrong

It says "command not found"

Close the Terminal window and open a new one. New commands only show up in new windows. If it still happens, paste the line from step 3 again.

It asks for my password

These apps never need your password. Press Ctrl + C to stop, and check you pasted the line from step 3 exactly.

Nothing happens when I press keys

Click inside the window first, so it's the one listening. If an app is open, press Esc or q to leave it.

My school or work network blocks the website

The install falls back to GitHub by itself. If that's blocked too, try again at home.

How do I remove an app?

Open pca, pick the app, and press x. Or type the app's name, then uninstall, like: roomy uninstall.
