pca

Project CLI Access is one command for every app here, all sixteen of them. Type pca, pick one with the arrow keys, press Enter. If it isn't installed yet, pca installs it first, and whatever is out of date, it updates by itself.

Install

curl -fsSL {{origin}}/pca/install.sh | sh

Paste it into Terminal, open a new window, and type pca. You don't need anything installed first: if Node.js is missing, the installer brings a private copy that only pca uses.

Commands

pcaThe picker. Enter opens an app, w shows what's new in it, u updates it, U updates everything, L switches every app between light, dark and following the time of day, x then x removes it.
pca totStraight into Tree of Thought. Same for any app: pca hum, pca locket, pca scout…
pca pigeon send pic.pngAnything after the app's name goes to the app.
pca listWhat's installed, and which version.
pca install allInstall every app.
pca updateCheck for updates now and get them all. (pca also does this by itself when it starts.)
pca auto dailyAlso update once a day, even when pca isn't open. pca auto off stops updating by itself.
pca look lightLight for every app. Also pca look dark, and pca look auto.
pca remove gossipUninstall one app.
pca uninstallRemove pca itself. Your apps stay.
pca delete-everythingEvery app, everything they saved, and every trace they left, then pca itself (or Shift + X in the picker). It shows you the whole list first and only goes ahead when you type delete everything.

pca installs everything from this website, so if the site moves, the projects move with it.
