How careful it is

  • ● Safe: it only looks. Enter runs it.
  • ● Careful: it moves, makes or changes something. hey asks "Run it? y/n" first.
  • ● Risky: it deletes things for good, uses sudo, runs a script from the internet, or can break things. You type yes first.
  • hey has its own rules for this, so a careless AI answer can't slip through as "safe".
