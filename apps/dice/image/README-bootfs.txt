DICE

This card has Dice on it. Put it in your Raspberry Pi and switch it on.

To set Dice up before you switch it on, make a dice.json file on the
website (https://djp7.pythonanywhere.com/dice) and drop it right here,
next to this note. Dice reads it on the next start-up, sets everything
up, then wipes the passwords out of it and renames it dice-applied.json.

You can also put dice.json on a USB stick and plug that into the Pi.

The user is "dice" and the password is "dice" until you change it
(in dice.json, or in Settings on the Pi).
