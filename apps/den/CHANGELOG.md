# What's new in den

## 2.0.0
A whole new den: everything a big code editor does, still made for learning.
- **A new look**: see-through panes over a soft, glowing background, a colour for every part (files amber, search sky, changes green, outline violet, Ember coral), drawn icons, and five themes: Ember, Dusk, Moss, Daylight and Frost.
- **Real terminals** in the panel under your code (Ctrl+`): colours, arrow keys, Python's own prompt, nano, top, git, pip. A page that reloads picks its terminals back up.
- **Changes (git)**: what changed since the last commit, with coloured bars beside changed lines and a line-by-line comparison; stage, commit (Ember can write the message), undo changes safely, switch branches, push and pull, and put a project on GitHub.
- **Search and replace in every file**, with match-case, whole-word, pattern and only-these-files options, and a preview of each replacement.
- **Mistakes as you type**: squiggles, red line numbers, a Problems list and F8 to jump between them (Python, JavaScript, JSON, CSS). The line a program stopped on gets one too.
- **Two files side by side** (⌘\\), drag tabs between sides; a minimap; indent lines; matching brackets; other uses of the word you're on; a path bar showing the function you're in.
- **Outline** of the file's functions, classes and headings; **⌘P** with `>` for commands, `@` for functions, `:` for a line.
- **Ember can change your code**: Apply on her code, Edit with Ember (⌘E) and "Fix it with Ember" always show you exactly what would change first.
- **Examples to start from** on the welcome page: a web page, a Python program, a quiz, an arcade game (code on the left, the game running on the right) and notes.
- **Files**: drag to move, drop files and folders from your computer to add them, open a terminal or search in any folder.
- Earlier versions now show what's different from what you have.
- A clickable status line: line and column, indent, language, branch, push and pull, mistakes, Ember's AI, colours.
- Typing stays quick in big files.
- In macOS Terminal, Ember (in den's start-up message) is drawn in whole blocks, so no thin lines run through her.

## 1.0.0
- The first version. Type `den` in a project folder and it opens in your browser: files, tabs, an editor that colours about 25 languages, a console, and Ember the fox.
- Run your code with one button (Python, JavaScript and more), answer `input()` questions in the console, and stop it any time.
- When something breaks, Ember explains the error in plain words, jumps to the line, and can install a missing module for you.
- "What's this?": put your cursor on a word and Ember explains it.
- Live previews for web pages (with their `console.log` and errors in den's console), Markdown, SVG and CSV.
- Ask Ember about your code with the free AI from Tree of Thought; code in her answers can go straight into your file.
- Saves as you type, keeps earlier versions of every file, and deleting moves things to den's bin.
